GitDOS — DOS в браузере, диск из GitHub
Автор: Sementsul Maxim. Сайт: https://sementsul.github.io/GitDOS/ · Репозиторий: https://github.com/sementsul/GitDOS/ . GitDOS Client: https://github.com/sementsul/GitDOS/releases/tag/1.0.0

GitDOS — браузерный Git клиент на основе DOSBox (движок js-dos v8, лежит локально), где диск C: — это GitHub-репозиторий: чтение, запись и автосохранение прямо в git. Дополнительные репозитории подключаются как папки C:\DISKS\<буква>. Интерфейс в стиле установщика Windows 98, RU/EN.

Web клиент для Windows:
GitDOS-win32-x64.zip

Для других ОС
Если вам нужна сборка для macOS или Linux, вы можете собрать её самостоятельно:

bash
npm install -g @gwicho38/nativefier
nativefier "https://sementsul.github.io/GitDOS" --platform mac  # или linux
📦 Что умеет
📁 Работа с дисками и Git
Диск = репозиторий: монтирование C: из публичного или приватного репо, доп. диски D:/E:…

Автосохранение изменений в GitHub (пуш только новых/изменённых файлов по git-sha, удаления — тоже).

Большие файлы до 100 МБ — через Git Data API (blob→tree→commit); чтение публичных файлов — через raw.githubusercontent.com (не тратит лимит API). Файлы >100 МБ — опционально через GitHub Release.

Профили подключения (наборы «главный репо + доп. диски»), переключение/дублирование.

История диска («Машина времени»): снимки прошлых версий (только чтение) и восстановление файла.

.gitdos.json — манифест: имя диска, автозапуск программы (run), скорость CPU (cycles).

🖥️ Интерфейс и управление
Лаунчер — список программ (.EXE/.COM/.BAT), запуск по клику.

Выборочное монтирование — грузить только нужные папки (быстрый старт больших дисков).

Загрузка файлов и .zip (архив распаковывается в выбранную папку), экспорт/импорт всего диска в .zip.

Редактор AUTOEXEC.BAT / CONFIG.SYS прямо в браузере.

Поделиться ссылкой ?repo=owner/name (+ QR-код) — публичные диски открываются одним кликом.

Индикатор лимита GitHub API, настройки DOSBox (cycles, звук), сброс локальных данных.

💾 DOS-утилита GITDOS
Полноценный git из DOS: статус, SAVE/COMMIT/PULL/LOG/DIFF, ветки (BRANCH/BRANCHES/MERGE/DELBRANCH), CHECKOUT/RESTORE/SHOW/TAG/RESET, NEWREPO, смена репозитория (SET REPO/BRANCH/PATH), профили, WHO, VER. Полный набор — GITDOS HELP.

⌨️ Удобства ввода
Поле ввода команд между экраном и логом — вставка текста в DOS (в терминале DOSBox вставки нет).

Голосовой ввод (Web Speech API): команды DOS голосом (VOICE) или задачи ассистенту (VOICE AI). Горячие клавиши: ScrollLock — команда DOS, Pause/Break — задача ассистенту.

Голосовые подсказки — звуковой сигнал перед записью голоса (speak).

🤖 Встроенный AI-ассистент (Claude)
GitDOS имеет встроенного AI-ассистента на базе Claude (Anthropic), который работает прямо внутри DOS-терминала.

🔧 Настройка
API-ключ вводится в настройках → блок «🤖 Ассистент» (хранится только в браузере, в код/коммиты не попадает).

Модель можно выбрать (по умолчанию claude-3-haiku-20240307).

Запросы идут напрямую в api.anthropic.com (ключ виден в браузере — для личного использования).

🎯 Возможности AI
Команда AI <вопрос> в DOS — ответ печатается прямо в терминал (кратко, ≤6 строк).

Авто-выполнение команд — ассистент может сам выполнять команды в DOS (цикл с обратной связью, видит вывод команд). Управляется тумблером «Авто-выполнение» (по умолчанию выключено — безопасность).

Управление программами — ассистент может ставить/удалять программы через INSTALL/UNINSTALL и запускать их через RUN.

Создание файлов — директива MAKE: <путь> позволяет ассистенту писать .BAT-скрипты, .TXT-файлы и исходный код прямо на диск.

Видение экрана (Vision) — ассистент может видеть скриншот DOS-экрана (опционально, увеличивает расход токенов).

Долговременная память — ассистент помнит факты между сессиями (хранятся в AIMEMO.TXT на диске).

Планировщик задач — автоматический запуск задач при старте диска или по расписанию (каждые N минут).

🎮 Управление AI из DOS
AI <вопрос> — задать вопрос ассистенту.

AIMACRO — список сохранённых макросов; AIMACRO <имя> — запустить макрос.

AIFILE — отправить содержимое текстового файла как задачу ассистенту.

LOGVOICE — включить полную озвучку логов (удобно без экрана).

🔊 Голосовое взаимодействие
Голосовой ввод (🎤 / VOICE AI) — продиктовать задачу ассистенту (распознавание RU/EN).

Озвучка ответов (TTS) — ответы ассистента проговариваются голосом (браузерный синтез речи).

Горячие клавиши: Pause/Break — задача ассистенту голосом.

Результат выводится прямо в DOS-терминал.

🏪 GitDOS Store (каталог программ)
Встроенный каталог программ, игр и драйверов — доступен прямо из DOS через команду INSTALL.

Публикация программ — выложите свою программу в каталог через веб-интерфейс или API.

Установка/удаление — INSTALL <id> / UNINSTALL <id>.

Каталог настраивается в «Общие настройки» → «🧩 Каталог программ».

bash

🌐 Публикация (GitHub Pages)
Запушить репозиторий в github.com/sementsul/GitDOS.

Settings → Pages → Source: GitHub Actions (workflow .github/workflows/deploy-pages.yml опубликует корень).

Сайт: https://sementsul.github.io/GitDOS/.

PWA: на опубликованном сайте включается сервис-воркер (sw.js, network-first — онлайн всегда свежая версия, кэш только для офлайна). На localhost он намеренно отключён, чтобы не мешать разработке.

🔒 Безопасность
GitHub-токен пользователь вводит в браузере (хранится в localStorage), в код/репозиторий он не попадает и не кладётся в ссылки «Поделиться». Для приватных репозиториев и записи нужен токен с правом repo.

AI-ключ Claude также хранится только в браузере и не попадает в код/репозиторий.

Заметки по разработке и грабли — docs/project-notes.md.
